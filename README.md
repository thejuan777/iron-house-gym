# Iron House

Sitio web responsive diseñado y desarrollado como propuesta digital para un gimnasio.

El proyecto está orientado a presentar planes de entrenamiento, actividades, entrenadores, galería y canales de contacto dentro de una experiencia visual moderna y adaptable a distintos dispositivos.

![Vista previa de Iron House](img/Vista%20previa%20de%20Iron%20House.png)

## Sobre el proyecto

Iron House fue desarrollado con una identidad visual oscura y deportiva, utilizando negro, gris y rojo como elementos principales del diseño.

La web incluye navegación responsive, presentación de planes según frecuencia de entrenamiento, checkout demostrativo, galería, contacto directo y acceso a la ubicación mediante Google Maps.

## Tecnologías

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Diseño responsive para desktop, tablet y móvil
- Menú mobile con panel lateral
- Planes de entrenamiento por frecuencia
- Checkout demostrativo
- Sección de actividades
- Presentación de entrenadores
- Galería de imágenes
- Integración con WhatsApp e Instagram
- Dirección vinculada a Google Maps
- Animaciones suaves de interfaz

## Planes

El sitio presenta tres modalidades de acceso:

- Pase diario
- 3 veces por semana
- Libre mensual

Cada opción dirige a un checkout donde se muestra automáticamente la información correspondiente al plan seleccionado.

## Checkout

El checkout muestra el plan, precio, frecuencia y beneficios seleccionados, además de permitir ingresar:

- Nombre
- Email
- Teléfono

Esta versión funciona como demostración y no procesa pagos reales ni almacena información.

## Estructura

- `index.html` — página principal
- `style.css` — estilos y diseño responsive
- `scrip.js` — navegación e interacciones
- `plans.js` — información de los planes
- `checkout.html` — flujo de checkout
- `checkout.js` — lógica del checkout
- `img/` — recursos visuales

## Próximas extensiones

La estructura del proyecto permite incorporar posteriormente autenticación, membresías, base de datos, identificación mediante QR e integración de pagos.
